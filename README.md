# お金の管理

クレジットの引き落としを差し引いた「本当の貯金」を日付ごとに確認するアプリ。GitHub Pages で公開しています。

- 今の残高・給料日と給料額・引き落とし日（固定）を設定
- 次の引き落とし額と、次の月の引き落とし額を入力
- 今日から1ヶ月後（次の月の引き落とし日まで）の残高をカレンダーで全日表示
  - 赤: 引き落とし後〜給料日（いちばん少ない期間＝本当の貯金）
  - 緑: 給料日後〜引き落とし
  - マイナスの日は濃い赤
- 使っていい金額（期間中いちばん少ない残高＝マイナスにならない上限）を表示
- 入力内容はブラウザ（localStorage）に保存
- 画面右下にバージョンとデプロイ時刻を表示
