# お金の管理

クレジットの引き落としを差し引いた「本当の貯金」を日付ごとに確認するアプリ。GitHub Pages で公開しています。

- 今の残高・給料日と給料額・クレジットの締日と引き落とし日（固定）を設定
- 次から3回分の引き落とし額を入力（分割払いの先の分も）
- 固定費（引き落とし以外: 家賃・光熱費・交通費など）を支払日・金額で設定。今月分は支払済みチェック可。「クレジットで払う」にするとその月の締めの分として翌月の引き落とし日に引かれる
- 今月を含めて3ヶ月分のカレンダーを月ごとに表示（左右の端（1/4）のタップ・スワイプで切り替え）
  - 残高と「使える（その日にカードで使っていい金額）」は、変わった日だけ表示
  - 背景色: 引き落とし後〜給料日（本当の貯金）はオレンジ、給料日後〜引き落としは青
  - 文字色: マイナスのときだけ赤
  - 使える金額（本当の貯金がマイナスにならない上限） = その日の利用分が引き落とされる日（締日の翌月の引き落とし日）以降でいちばん少ない残高
- 入力内容はブラウザ（localStorage）に保存
- 画面右下にバージョンとデプロイ時刻を表示
