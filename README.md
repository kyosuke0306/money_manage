# お金の管理

クレジットの引き落としを差し引いた「本当の貯金」を日付ごとに確認するアプリ。GitHub Pages で公開しています。

- 今の残高・給料日と給料額・クレジットの締日と引き落とし日（固定）を設定
- 次の引き落とし額と、次の月の引き落とし額を入力
- 今日から1ヶ月後（次の月の引き落とし日まで）をカレンダーで表示
  - 残高と「使える（その日にカードで使っていい金額）」は、変わった日だけ表示
  - 背景色: 引き落とし後〜給料日（少ない期間）はオレンジ、給料日後〜引き落としは青
  - 文字色: マイナスのときだけ赤
  - 使える金額 = その日の利用分が引き落とされる日（締日の翌月の引き落とし日）以降でいちばん少ない残高
- 入力内容はブラウザ（localStorage）に保存
- 画面右下にバージョンとデプロイ時刻を表示
